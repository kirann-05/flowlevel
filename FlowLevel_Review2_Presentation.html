Criterion 1 — System Design

Criterion 2 — Implementation of Modules

Module 2: Level Collection + Skill Encoder

Level Collection

  • 10,000 PPO rollout episodes
  • Validity filter: box not in corner, path exists
  • 1,213 valid levels retained (12.1%)
  • Difficulty: box_distance (O(1), never hangs)

Skill Encoder Architecture

  • Input: 4D metric vector [box_dist, n_boxes, sol_len, solvable]
  • Encoder: 4 → 64 → 32 → 16 (z-score normalised)
  • Decoder: 16 → 32 → 64 → 4 (reconstruction)
  • Loss: MSE · Adam lr=1e-3 · 100 epochs
Criterion 2 — Implementation of Modules

Module 3: Diffusion Model + API

Diffusion Architecture

  • DDPM (Ho 2020) · T=1000 · linear β schedule
  • Flat UNet — no MaxPool2d (5×5 collapses to 0×0 after 3 pools)
  • FiLM conditioning at every block: x = x·(1+γ) + β
  • 48D joint conditioning: 16D skill + 32D timestep embed
  • AdamW · batch 64 · 150 epochs · GTX 1650 ~35s

API (FastAPI + Uvicorn)

  • GET /health — system status
  • GET /generate/{skill} — level at skill 0–1
  • GET /compare — easy vs hard side-by-side
  • Response time: <100ms

Honest Limitation
